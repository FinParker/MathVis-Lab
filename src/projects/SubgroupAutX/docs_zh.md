# Aut(X) 子群 (S3 群)

对于集合 $X=\{1,2,3\}$，$Aut(X)$ 是所有从 $X$ 到 $X$ 的双射函数构成的群，即**对称群 $S_3$**，大小为 $3!=6$。

以下是所有元素的置换表示：

*   $e$: 恒等变换 $(1, 2, 3) \to (1, 2, 3)$
*   $(12)$: 交换 1 和 2，保持 3 不变
*   $(23)$: 交换 2 和 3，保持 1 不变
*   $(13)$: 交换 1 和 3，保持 2 不变
*   $(123)$: 1 移到 2，2 移到 3，3 移到 1 (左循环移位)
*   $(132)$: 1 移到 3，3 移到 2，2 移到 1 (右循环移位)

根据群论中的**拉格朗日定理**，子群的大小必须能整除 6。因此，子群的大小只能是 **1, 2, 3, 6**。

## 所有子群一览

### 1. 平凡子群 (大小为 1)
*   $E = \{e\}$

### 2. 二阶子群 (反射对称)
这类子群由对换（自逆元素）生成。
*   $H_1 = \{e, (12)\}$
*   $H_2 = \{e, (23)\}$
*   $H_3 = \{e, (13)\}$

### 3. 三阶子群 (旋转对称)
这类子群由循环位移生成，也称为**交错群 $A_3$**。
*   $H_4 = \{e, (123), (132)\}$

### 4. 全群 (大小为 6)
*   $S_3$: 包含所有可能的置换。

## 结构理解：子群格 (Subgroup Lattice)

我们可以通过**子群格图**（Hasse图）来观察这些子群之间的包含关系：
*   **顶层**：$S_3$（全群）
*   **中间层**：$H_4$（唯一的三阶正规子群）以及 $H_1, H_2, H_3$（三个二阶子群）
*   **底层**：$\{e\}$（平凡子群）

**关键洞察**: $S_3$ 是最小的**非交换群**（非阿贝尔群）。
例如，先交换 (23) 再交换 (12) 的结果是 $(12) \circ (23) = (123)$，而反过来 $(23) \circ (12) = (132)$。
这种**顺序相关性**是群论和范畴论中的核心概念。
